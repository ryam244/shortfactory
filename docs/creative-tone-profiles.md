# クリエイティブトーンプリセット

このファイルは、同じ訴求構成でも画面の印象を変えられるように、採用候補の3トーンを固定するための記録です。フック比較では、トーンを変えずに冒頭だけを差し替えます。

## 1. 固定IPキャラクター

シリーズの中心。片側ヘアクリップ、青緑スカーフ、星形バッジを識別点として固定します。キャラクターを毎回ランダム生成せず、表情・手のポーズ・小物だけを差し替えます。

実装素材は `packages/video/scripts/lib/editorial-assets.ts` にあります。

## 2. 実物寄りのリアル人物

現実の店舗や利用場面を見せ、信頼感を出すトーンです。人物の自然さだけでなく、商品・手元・背景の光を揃えます。キャラクターIPを主役にせず、利用結果や商品説明を優先します。

比較用の生成物は `outputs/batch-realistic-v1.mp4` です。

## 3. 淡い色調のイラスト人物

淡いクリーム、青緑、コーラルの配色で、親しみやすく説明するトーンです。人物と背景を同じ画風に揃え、人物の手の向きと説明対象の位置を一致させます。

比較用の生成物は `outputs/batch-explainer-v1.mp4` です。

## 運用ルール

- フック比較は `question` / `empathy` / `promise` だけを変更する。
- キャラクター、リアル人物、淡い人物を同じ比較グループに混ぜない。
- 画風の比較と訴求の比較を別テストにする。
- 公開・商用利用前に、画像生成サービスと音源サービスの利用条件を確認する。

`realistic-person` と `pale-illustration-person` は、対応する `full_scene` または `full_scene/scene-XX` 素材が登録されている場合、自動的に完成シーン描画へ切り替わります。素材がない場合は動画を壊さず、固定IPキャラクターモードへフォールバックします。
