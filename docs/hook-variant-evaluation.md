# フック比較テスト

同じトーン・同じ本文・同じ証拠・同じCTAで、冒頭だけを比較するための評価表です。今回は固定IPキャラクター版で実動画を生成しています。

## 比較動画

- [問いかけ型](../packages/video/out/hook-variants/question/gift-question.mp4)
- [共感型](../packages/video/out/hook-variants/empathy/gift-empathy.mp4)
- [結果先出し型](../packages/video/out/hook-variants/promise/gift-promise.mp4)

## 視聴者評価

各動画を音あり・音なしでスマートフォン表示し、5段階で記録します。最初の評価では、動画の順番を視聴者ごとに変えて順番の影響を減らします。

| 評価項目 | 問いかけ型 | 共感型 | 結果先出し型 |

| 続きを見たい |  |  |  |

## 判定ルール

- 平均点だけでなく、「2秒で自分向け」と「続きが見たい」を重視する。
- 1人の好みで決めず、最低5人分を集める。
- フックを決めた後に、トーン（IPキャラクター／リアル人物／淡い人物）を比較する。
- 視聴者評価は品質仮説の確認であり、公開後の視聴維持率・完視聴率・保存数とは別の指標として記録する。
